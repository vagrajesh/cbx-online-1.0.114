Sample branding files for CBX-Connect (white "CBX" lettering on a transparent background).

To use them: copy logo.png and favicon.png into data\branding\ next to the app
(or upload them from Settings -> Branding once signed in as the owner).
Set CBX_LOGO_FILE=data\branding\logo.png and CBX_FAVICON_FILE=data\branding\favicon.png in .env
if you want them as the install defaults; anything the owner uploads in Settings wins over .env.
